# Bpho_computational2026
Oliver and Richard's code for the 2026 BPhO computational challenge. Includes the latex document summarising our solutions.
Note that running Q10 and the LCAO extensions may require a good network (preferably > 40Mbps)
The link to the photoelectric simulator is    https://oliver-yang-01.github.io/Photoelectric-effect-simulator/     (which can also be found in the latex document)
